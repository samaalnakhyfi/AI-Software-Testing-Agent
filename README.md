# AI Software Testing Agent

An AI-assisted software testing project built with Python, Playwright, and Ollama.

The project automates web testing, analyzes test results using a local AI model, and generates an HTML dashboard with testing insights.

## Features

•⁠  ⁠Automated web testing using Playwright
•⁠  ⁠AI-assisted test case generation
•⁠  ⁠Automated test execution
•⁠  ⁠AI-powered result analysis
•⁠  ⁠Test reports in JSON format
•⁠  ⁠HTML dashboard with test statistics
•⁠  ⁠Success rate calculation
•⁠  ⁠AI-generated testing recommendations

## Technologies

•⁠  ⁠Python
•⁠  ⁠Playwright
•⁠  ⁠Ollama
•⁠  ⁠Qwen2.5-Coder 7B
•⁠  ⁠HTML and CSS
